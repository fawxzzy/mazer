Only interior cells are added, start and goal never move, the fringe cells past the felt saturation are never walled up, and the pass is deterministic per seed (seeded xorshift) with a kill switch `setMazeQualityPassEnabled`. The pass also holds the maze seen with the tuner's loop connectors closed (felt steps, torus and planar route), so the recorded loop and wrap savings stay exact (legacy-wrap-fade identity). On a gate-decided maze the edit is dropped unless the re-placed gate keeps exactly the same gated and ungated saving (the tuner priced the felt number for that gate).
