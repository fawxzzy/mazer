# 2026-11-15 MAZER-VIS-051 round 2 saturated trail cores, core-vs-underlay contract

- WHAT changed: `src/render/trailPalette.ts` core stops are now 6 saturated neon colours (cyan 0x10dcff, azure, laser blue, indigo, violet 0xb85cff, magenta 0xdc46f0; the warm apricot end is gone), bloom stops follow; sheen sweep slowed (period 3000 to 6000 ms), sheen hue shift 0.05 to 0.02, sheen core lift 0.35 to 0.3, pulse core lift 0.1 to 0.08 so the per-redraw step bounds (8 core / 10 at a 4-frame gap, bloom 18/24) still hold with saturated stops. Tests `trail-iridescence`, `board-tile-layer`, `marker-trail-legibility` updated.
- WHY: owner still saw violet/magenta/blue as pastel. The old "core >= 3:1 on the bare chip" pin forced core luminance >= 0.47.
- Rule (contract change): the trail core is never drawn on the bare chip. It sits on the near-opaque dark underlay (void at alpha 0.94, itself >= 3:1 off the chip). The pin is now core vs underlay >= 4.5:1 on chip, rim and gap, for every stop, every in-between colour, every sheen/pulse sample (measured worst 5.35:1), and the faded tail (alpha 0.7) stays >= 3:1 on every floor. Bare-chip worst is now 1.72:1 (0xa964ff) and is reported, not pinned. Accessibility holds because the core is separated from its actual background, not from the chip beneath the underlay.
- Trade-off: the warm apricot end was dropped; saturated warm stops collide with the goal-red (>= 120) and start-gold (>= 75) colour-distance guards.
