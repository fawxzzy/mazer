# 2026-11-15 HAZ-004 slice H3: Pulse Gate playable behind the hazard lab flag

- WHAT changed: the Pulse Gate is playable with the hazard layer on (`?lab=hazards`, default OFF). The maze worker builds the hazard overlay next to the maze when the job carries `hazard: { enabled, level }` (workers cannot read the query or storage, so the scene passes it); the host parks it in a WeakMap keyed by the maze object and `installLegacyHazardGateLayer` takes it once, falling back to a main-thread compute when a maze was built synchronously or for another level. New `src/legacy-runtime/legacyHazardGateController.ts` owns the gate state: arrival-tick legality (a step taken at world tick t onto a gate closed at t+1 is a wall bump), the A3 eject (a gate closing on the player pushes them one cell back along the trail through the normal move path), the menu demo witness replay (only once the player is past level 10), the intro copy latch and the receipt stamp. New `src/render/hazardGateLayer.ts` draws the gates on their own canvas: bar style shows the next tick (solid = closed next, dashed = open next), alpha shows now (full = closed, 0.72 = open), a closing gate ramps over 4 steps, reduced motion keeps the static state, and the view redraws only when tick, ramp step, layout or fade change. Every bar has a void-coloured keyline. `MenuScene` wires the world clock into the real input path (keyboard, touch, pointer), checks arrival legality in `applyLegacyWorldTurnPlayerMovement`, ejects in `updateHazardWorldClock`, and stamps `hazardScheduleVersion` / `hazardDigest` / `exposureStage` into play receipts (local history and the remote receipt jsonb). `updateHazardWorldClock` no longer resolves the speed profile while the clock is idle or play is inactive.
