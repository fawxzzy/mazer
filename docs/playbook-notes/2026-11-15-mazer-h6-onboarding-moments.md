# 2026-11-15 - Hazard slice H6: exposure stage, intro cards (HAZ-008), tier pips (PROG-007), hazard Guide rows, audio events

- WHAT changed: a persisted, local hazard exposure record (`src/mazer-core/hazards/exposure.ts`: version, stage, intros shown, last tier pip) with migration and tamper handling; pure onboarding decisions in `src/legacy-runtime/legacyHazardOnboarding.ts` (which intro card or tier pip a level start shows, show-once, which hazard rows the Guide lists); a non-modal card/pip view (`src/render/hazardMomentRenderer.ts`) and hazard Guide glyphs (`src/render/guideHazardGlyph.ts`); four hazard rows in `legacyGuideContent.ts` (one copy source for the Guide and the card); six gentle hazard sound kinds plus named audio events (`legacyHazardAudioEvents.ts`). MenuScene only asks at level start/clear and draws. All of it sits behind the hazard layer flag (default OFF).
- WHY it changed: roadmap slice H6. A new hazard kind needs a one-line, skippable introduction the first time it appears, and each tail unit that lands needs a small, readable signal, without ever changing what a flag-off player sees.
- Rule: the exposure stage is clamped where it is used (`min(scheduled(level), stage)`), never where it is read, so a tampered or future save cannot build a harder maze than the level allows and a progression reset never loses it. Merges are max-wins. Card and Guide copy come from one row in `legacyGuideContent.ts`; copy claims are pinned to `docs/contracts/mazer-hazard-schedule.v1.json` by a test.
- Rule: with the flag off `createHazardOnboarding` returns null: no storage read, no view built, Guide rows are the same `LEGACY_GUIDE_ROWS` array. Only kinds in `HAZARD_ONBOARDING_LIVE_KINDS` show a card, pip or Guide row (H3/H4/H5/H8 add theirs); the stage still advances on schedule for every kind.
- Failure Mode: a card timed from level start expires during the maze build-out, before anyone sees it. Its timer starts on the first frame it is actually visible (play, no overlay, build-out finished).
- Evidence: `tests/core/hazards/exposure.test.ts`, `tests/reset/legacy-hazard-onboarding.test.ts`, the updated `tests/reset/legacy-guide-content-drift.test.ts`, `tests/reset/legacy-sound-effects.test.ts` and `tests/core/hazards/source-boundary.test.ts`; Playwright screenshots at 390x844 and 1280x720 with `?lab=hazards&previewLevel=10|36|51|111`.
- Status: source only, behind the flag. Not checked on a real phone.
