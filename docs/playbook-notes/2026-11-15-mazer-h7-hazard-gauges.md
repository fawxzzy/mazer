# 2026-11-15 Mazer slice H7: hazard gauges, band assertions and the hazard-menu runway

- WHAT changed: `scripts/analysis/progression-gauges.ts` gained two commands and a `HAZARD_GAUGES` catalogue: `hazards` (gauge corpus over the shipped ladder plus the contract 2.5 band assertions, `--assert` / `--assert=integrity`) and `runway` (the hazard menu tape, the shipped saturation freeze, and the real overlay measured with the freeze lifted). New `scripts/analysis/lib/hazardGauges.ts` measures `hazardDelay`, `escapeSlack`, bot contacts (exact / limited horizon / myopic) and clean rate; `scripts/analysis/lib/hazardGaugeCorpus.ts` runs the real H2 overlay (`resolveLegacyHazardOverlay`) on each shipped maze and evaluates bands. Test: `tests/core/hazards/h7-hazard-gauges.test.ts`. No `src/` change, no play change.
- WHY it changed: roadmap slice H7. The 2.5 assertions need a measurement that does not trust the allocator, and the runway needs a measured number, not the planning estimate.
- Rule: the gauge solver shares no code with `src/mazer-core/hazards`. It uses production movement (`resolveLegacyWalkableGridNeighbors`), re-derives the gate and Sentry formulas from the contract, and solves with its own forward time-layered BFS and backward fixed point. A bug in the allocator, placement or H2 verdict shows up as a disagreement. The unit test pins it to the brute-force oracle with a gate planted on the route and to a hand-worked corridor; flipping the gate inequality fails 3 of 5 tests.
- How to run (package.json is on the doNotEdit list, so there is no npm script and no new CI workflow; the integrity slice runs in `npm run test` through `tests/core`):
  - `npx vite-node --script scripts/analysis/progression-gauges.ts hazards --assert` (default L1..300, step 1, 2 seeds, both ladder boards; about 2.2 min on node 1x)
  - `npx vite-node --script scripts/analysis/progression-gauges.ts hazards --assert=integrity` (exit 1 only on integrity failures; curve assertions are reported)
  - `npx vite-node --script scripts/analysis/progression-gauges.ts runway` (default L200..480 step 10, 4 seeds)
