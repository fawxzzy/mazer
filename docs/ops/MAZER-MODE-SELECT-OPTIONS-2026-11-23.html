Recommendation

A Stack now, C Tiles when there are more than 3 entries. A is the fewest taps while the list is short and matches the existing sheets. The layout plan is data-driven, so moving to C later is a variant swap. B loses: it hides modes and scales worst.

Same in all three

  • Reached after Play (the tap-to-play prompt and the menu Play both go through it). ?mode=play deep links skip it.
  • Back to Menu always present and always secondary. No data changes until a mode is chosen.
  • Level and Rank shown are Endless's own; progression, saves and leaderboard are tied to the mode (contract section 10). Existing saves become Endless with no rewrite (section 12).
